Idea Gonzalo:

Una aplicación que sirve como un panel de control único para cualquier jugador de videojuegos, en la aplicación se centralizará todas las cuentas que tengas en las distintas plataformas 
como Steam, Epic Games, Playstation, etc... dentro puedes consultar tu biblioteca de juegos, trofeos, amigos y todo desde un mismo sitio.

¿Quién lo sufre?
Los jugadores de videojuegps multiplataforma, como un PC, Playstation y más.

¿Con qué frecuencia?
Diaria o semanalmente, cada vez que quieran jugar a algo o conectarse con algún amigo.

¿Cuál es el impacto?
La pérdida de tiempo al tener que abrir distintas plataformas para ver ya sea dónde tienes un juego, qué amigos están conectados, que trofeos te faltan en diferentes juegos, etc...
